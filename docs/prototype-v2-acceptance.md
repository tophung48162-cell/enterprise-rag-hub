# 原型 V2 验收记录

日期：2026-10-26（Asia/Shanghai）

## 对照截图的模块

| 截图功能 | 新版实现 |
| --- | --- |
| 工作台 | 知识资产、问答应用、处理动态、主流程入口 |
| 模型服务 | OpenRouter、AIHubmix、通义；LLM、Embedding、Rerank 配置 |
| 知识库 | 独立知识空间，文件任务、分块预览、检索测试 |

| 运行日志 | 问题、回答、模型、角色、输入/输出 Tokens、总耗时 |

## 浏览器验证

- 管理员可见六个一级模块。
- 特色菜知识库包含 PDF 和 Word；分块工作区为三栏布局。
- 人工修订分块后显示「待重新索引」，重建任务可完成。
- 新建「原型验收知识库」后进入独立 ID 路由，初始无文件。
- 导入示例 Markdown、CSV 后，当前知识库出现两份文件、分块和构建任务。
- 构建完成后检索「差旅报销需要哪些材料」命中刚导入的资料。
- 产品支持助手从草稿发布后，开始对话按钮可用。
- 饮食助手回答命中修订后的过桥米线分块，引用显示正确文件、页码与原文。
- 本轮问题生成匹配的日志，输入/输出 Tokens 与回答用量一致。
- 管理人员隐藏模型模块，使用者仅保留工作台、应用、对话；使用者直达模型地址显示 403。
- 手机 390×844 工作台与对话布局可用，文档宽度与视口宽度均为 390，没有整页横向溢出。

## 已修复的回归

浏览器测试发现自动滚动函数返回 Promise 时被 React 误作 effect 清理函数，导致问答完成时页面异常。已用显式 effect 函数体修复，并添加完整问答用例防止复发。

## 实现边界

当前是前端原型，保存到当前浏览器。解析、OCR、向量检索、Rerank、LLM 调用、连通测试和 Token 消耗仍是演示；不会上传资料或调用收费模型服务。后端开发保持在用户确认前端之后。
